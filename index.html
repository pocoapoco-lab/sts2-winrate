📱 ホーム画面に追加してアプリ感覚で使う 無料・約30秒

Threads・LINEなどのアプリ内ブラウザから開いた場合は、まずメニューから「Safariで開く」か「Chromeで開く」を選んでね。

🍎 iPhone（Safari）

  1. Safariでこの勝率トラッカーを開く。
  2. 画面下のアドレスバー左側の「≡」（横線3本） → 「共有」をタップ。
    ※共有マーク が直接表示されている場合は、そこをタップ。
  3. 共有メニューを下にスクロールして「ホーム画面に追加」を選ぶ。見当たらない場合は「アクションを編集」を確認。
  4. 「Webアプリとして開く」をオンにして、「追加」をタップ。

🌐 iPhone（Chrome）

  1. Chromeでこの勝率トラッカーを開く。
  2. アドレスバー付近の共有マーク をタップ。
  3. 「表示を増やす」 → 「ホーム画面に追加」を選ぶ。
  4. 内容を確認して「追加」をタップ。

🤖 Android（Chrome）

Chromeの「︙」メニューから「ホーム画面に追加」または「アプリをインストール」を選んでね。

※勝敗の記録は端末内に保存されます。ブラウザ版とホーム画面版で記録が共有されない場合があるため、記録済みの人は追加後に確認してください。
